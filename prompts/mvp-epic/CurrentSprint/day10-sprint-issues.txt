## Architecture Improvements Identified

### Dependency Injection Pattern
Current direct imports make testing difficult. Recommended pattern:
```typescript
class HealthCheck {
  constructor(
    private dbClient: SupabaseClient,
    private httpClient: typeof fetch
  ) {}
}
```

### Test Factory Pattern
Create reusable test factories for complex objects:
```typescript
export const createMockHealthCheckResult = (overrides = {}) => ({
  status: 'healthy',
  service: 'database',
  responseTime: 100,
  ...overrides
});
```

### Mock Service Workers Configuration
Implement proper MSW setup for external API testing:
```typescript
export const handlers = [
  rest.head('https://generativelanguage.googleapis.com/', (req, res, ctx) => {
    return res(ctx.status(200));
  }),
];
```

1. **Mock early, mock completely** - Partial mocking leads to unexpected failures
2. **Environment variable mocking is tricky** - Injection pattern is more reliable
3. **External API testing requires careful setup** - MSW provides better simulation
4. **Floating point comparisons need tolerance** - Use appropriate assertion methods
5. **Time-based functionality needs deterministic testing** - Mock time consistently
