**Test**: `src/lib/__tests__/supabase.test.ts > should throw error if environment variables are missing`
**Issue**: Mock module setup is incorrect, causing vitest import errors
**Root Cause**: Module mocking in vitest requires proper export structure

**Proposed Solution**:
```typescript
// Fix the mock to properly export the env module
vi.doMock('../env', async (importOriginal) => {
  const actual = await importOriginal()
  return {
    ...actual,
    env: {
      VITE_SUPABASE_URL: undefined,
      VITE_SUPABASE_ANON_KEY: undefined,
    },
    validateEnv: vi.fn(() => {
      throw new Error('Missing required Supabase environment variables')
    }),
  }
})
```
